# 📚 Трекер обучения и прогресса по курсам

Простое веб-приложение для отслеживания прогресса обучения по курсам.

## 🛠 Технологии

- **Frontend:** React, React Router, SCSS
- **Backend:** Node.js, Express.js
- **База данных:** PostgreSQL
- **Сборка:** Webpack

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных PostgreSQL

Создайте базу данных:

```sql
CREATE DATABASE course_tracker;
```

При необходимости измените параметры подключения в файле `server/index.js`:

```javascript
const pool = new Pool({
  user: 'postgres',
  host: 'localhost',
  database: 'course_tracker',
  password: 'postgres',
  port: 5432,
});
```

### 3. Запуск приложения

**Запуск backend сервера (терминал 1):**

```bash
npm run server
```

Сервер запустится на порту 5000.

**Запуск frontend (терминал 2):**

```bash
npm start
```

Приложение откроется в браузере на порту 3000.

## 📖 Функционал

### Каталог курсов
- Создание новых курсов с названием и описанием
- Просмотр списка всех курсов
- Удаление курсов
- Отображение общего прогресса по каждому курсу

### Модули
- Добавление модулей к курсам
- Порядок модулей автоматически нумеруется

### Уроки
- Добавление уроков к модулям
- Отметка прохождения уроков
- Автоматический расчёт прогресса в процентах

### Заметки
- Добавление заметок к урокам
- Просмотр всех заметок по уроку
- Дата создания заметки

### Статистика
- Общее количество курсов
- Общее количество уроков
- Количество пройденных уроков

## 🔌 API Endpoints

### Курсы
- `GET /api/courses` - Получить все курсы
- `POST /api/courses` - Создать новый курс
- `DELETE /api/courses/:id` - Удалить курс

### Модули
- `GET /api/courses/:courseId/modules` - Получить модули курса
- `POST /api/courses/:courseId/modules` - Создать модуль

### Уроки
- `GET /api/modules/:moduleId/lessons` - Получить уроки модуля
- `POST /api/modules/:moduleId/lessons` - Создать урок
- `PUT /api/lessons/:id/toggle` - Переключить статус прохождения

### Заметки
- `GET /api/lessons/:lessonId/notes` - Получить заметки урока
- `POST /api/lessons/:lessonId/notes` - Создать заметку

## 📝 Примечания

- Приложение использует каскадное удаление: при удалении курса удаляются все его модули, уроки и заметки
- Прогресс рассчитывается как процент пройденных уроков от общего количества
- Все данные хранятся в PostgreSQL базе данных
